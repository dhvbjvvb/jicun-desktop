即存 for Windows —— 装之前看这几句
====================================

1) 不用装任何依赖
   .NET 运行时、Windows App SDK 运行时、VC++ 运行库都已经打包在里面了，
   装完直接用，不需要另外去装什么。

2) 系统要求
   64 位 Windows 10 1809（build 17763）或更高版本 / Windows 11。

3) 安装不需要管理员权限
   按当前用户装在你自己的目录里，不会弹 UAC。

4) 如果 Windows 弹了蓝色的「Windows 已保护你的电脑」
   点「更多信息」→「仍要运行」就行：
   这个安装包还没有代码签名证书，不是病毒。
   （少数杀毒软件也可能误报，同样可以放心。）

5) 卸载
   在「设置 → 应用 → 已安装的应用」里搜「即存」卸载，或用开始菜单里的「卸载 即存」。
   卸载前如果程序还在运行，会弹窗让你一键关掉；卸载会把本地数据一起删掉
   （设置、观看历史、下载记录、缓存），但不会动你自己下载的视频 / 图片 / 音频。

6) 联网
   程序启动不需要联网；解析、下载这些功能需要网络。
